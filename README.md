# Tacet

一个 Android 应用，用一个总开关管理选定应用的广告域名过滤与自动跳过。

Tacet 是音乐术语，意为「休止」。项目名取这个意思，应用显示名为「清净」。

- Android 11 及以上，无需 root。
- 全部在手机本机运行，不连接电脑、不上传数据、不依赖远端模型或自建服务器。
- 无第三方运行库，构建过程不需要 Gradle，也不需要联网下载依赖。

## 能力

| 能力 | 做法 | 能处理 | 做不到 |
| --- | --- | --- | --- |
| 广告域名过滤 | 本地 `VpnService`，只路由两个虚拟 DNS 地址 | 独立广告服务域名上的开屏、插屏、横幅请求 | 与正常内容共用接口的广告；应用自带加密 DNS；已缓存广告 |
| 自动跳过 | 无障碍服务匹配控件并点击 | 开屏「跳过」、切回前台广告、可关闭的广告弹窗 | 需要先出现才能点，广告会短暂显示；无跳过按钮的广告 |
| 按应用开关 | 每个应用独立控制两项能力 | 只处理你在意的应用 | — |

默认只处理哔哩哔哩与养基宝，其他应用可在「管理」中添加。哔哩哔哩默认只用自动跳过、不开网络过滤，避免影响应用内内容和推荐。

## 已知限制

- **开屏会短暂闪现。** B 站开屏数据来自 `/x/v2/splash/*` 接口，与正常业务共用主域，无法只拦掉它；自动跳过必须等界面出现后才能点击。要完全不显示只能修改客户端本身。
- **同一时间只能有一个 VPN。** 与代理类应用（如 OKZ）互斥。检测到其他 VPN 时本应用不会抢占，自动跳过仍可单独工作。
- **规则跟随应用版本。** 应用更新可能改变控件标识或域名，需要重新适配。
- 支持某个广告 SDK 的跳过控件，不代表覆盖该 SDK 的所有广告位置。

## 使用

1. 安装 `tacet.apk`。
2. 打开总开关，按提示允许本地 VPN 与无障碍服务。
3. 需要调整时进「设置」：按应用开关能力、编辑域名规则与白名单、查看运行记录。

系统快捷设置里可添加「广告过滤」磁贴，用于快速开关。

关闭总开关会主动释放 VPN 接口并停止全部自动点击。开机后在授权有效、无其他 VPN 占用时尝试恢复。

## 构建

需要 Python 3、JDK 17、Android SDK Platform 35 与 Build Tools 35.0.0。不依赖 Gradle，不需要联网。

```sh
python3 build.py --sdk /path/to/android-sdk --java /path/to/jdk --test
```

`--sdk` 也接受直接解压的 build-tools / platform 目录。首次构建在 `.signing/` 生成本地更新签名，保留它以便后续版本覆盖安装；**不要提交或分发 `.signing/`**。

可选参数：`--work <目录>` 保留中间产物，`--output <路径>` 指定 APK 输出位置。

## 测试

```sh
python3 build.py --sdk <sdk> --java <jdk> --test          # 37 项核心检查
python3 test/run-device-tests.py --sdk <sdk> --java <jdk> \
    --app-build <构建目录> --work <临时目录>              # 手机端真实接口检查
```

- `test/CoreTests.java`：域名标签边界、白名单优先级、畸形 DNS 报文、IPv4/IPv6 包长与校验和。
- `test/DeviceTests.java`：真实 VPN 接口上的 IPv4/IPv6、UDP/TCP、白名单热更新、开关释放与恢复、应用选择变更。测试 APK 用同一签名构建，执行后自动卸载。

协议测试通过不代表真实应用中的广告都被去除，两者需分别验证。

## 目录

```
AndroidManifest.xml        应用清单
assets/domains.json        广告域名规则
assets/ui-rules.json       界面匹配规则
src/                       源码（Java，无第三方依赖）
res/                       资源
build.py                   构建脚本
test/                      协议测试与设备测试
```

规则文件带版本号，改动会随新 APK 发布；域名自定义规则可在应用内直接修改。

## 隐私

界面内容、域名查询只在本机处理。运行记录仅在内存中保留最近 100 条域名与规则命中信息，应用退出即清空。不保存截图、账号、完整 URL 或请求正文，不上传任何数据。
