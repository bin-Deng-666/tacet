# 分享材料

发布到小红书、抖音、B 站的图文素材与文案。

这套材料不是同一份内容复制三遍。三个平台的标题长度算法、封面比例、标签体系、配乐要求都不一样，所以按平台分别准备。

## 目录

```
小红书/    6 张 1080×1440（3:4） + 文案.md
抖音/      6 张 1080×1440（3:4） + 文案.md
B站/       1 张 1920×1080（16:9）封面 + 5 张 1080×1440 配图 + 文案.md
```

每个平台的 `文案.md` 包含：标题候选（已按该平台长度规则校验）、正文、标签、配图顺序、发布要点、发布后不可改的项。

## 叙事结构

六段固定顺序，从痛点走到上手。**痛点放在最前面，第一句就是场景，不是功能介绍。**

| 序号 | 内容 | 讲什么 |
| --- | --- | --- |
| 01 | 封面 | 开屏画面 + 圈出右上角「跳过」+ 手指。一眼看到问题在哪 |
| 02 | 问题 | 时间条对比：以前 3.0 秒 vs 现在约 0.5 秒 |
| 03 | 能力 | 三件事：拦域名、点跳过、分开管 |
| 04 | 界面 | 真实手机截图，首页只有一个开关，细节在二级页 |
| 05 | 边界 | 先说做不到的四条 |
| 06 | 上手 | 三步 + 仓库地址 |

首图必须用 `01-封面.png`，不要换成截屏。

## 视觉规范

- 背景 `#F6F4EF`（暖白），正文 `#74706A` 略深，强调色 `#9B624B`（陶土）
- 标题用宋体（Songti SC Black/Bold），正文用 Hiragino Sans GB W3，数字用 Avenir Next
- 左右边距 88px（16:9 封面为 110px）
- 所有正文文字对比度 ≥ 4.5:1（WCAG AA）
- 生成脚本画完每张卡片后自动校验：边距越界、元素重叠、是否侵占页脚区、文字对比度

## 平台差异

| | 小红书 | 抖音 | B 站 |
| --- | --- | --- | --- |
| 形态 | 图文笔记 | 图文作品 | 专栏 |
| 标题上限 | 20（ASCII 每 2 字符计 1） | 20 | 80，建议 30 内 |
| 图片比例 | 3:4 | 3:4 | 16:9 封面 + 3:4 配图 |
| 配乐 | 不需要 | **必须选，发布后不可改** | 不需要 |
| 发布后图片 | 可换 | **不可改** | 可改 |
| 修改额度 | 无上限 | 每作品 5 次 | 每篇 3 次 |

## 配乐（抖音）

内容性质是工具类图文，节奏平缓，没有卡点也没有情绪起伏。选曲要求：

- 无人声、无歌词，时长 ≥ 60 秒
- 节奏轻、鼓点不抢，不要热门卡点音乐
- 不要抒情钢琴曲（如「柔情似水」这类），情绪偏软，和工具内容不搭

在发布页「扩展信息 → 选择音乐」里搜 `Lo-fi` 或 `轻电子`，挑 BPM 90 以下、编曲简单的。试听判断：前 15 秒不出现明显人声或强旋律钩子，音量起伏小，不干扰读文字。

## 重新生成图片

图片由脚本从真实手机截图排版生成。截图来自应用实际运行状态（首页、应用保护选项）。

如果界面改了，需要重新截图再重排。文案里的数字（源码行数、APK 体积、测试项数）跟随版本变化，改版后同步更新：

- 源码行数：`find src -name '*.java' | xargs wc -l`
- APK 体积：构建后看 `tacet.apk` 大小
- 测试项数：`test/CoreTests.java` 与 `test/DeviceTests.java` 的检查条数

## 注意

材料里公开了仓库地址和 MIT 许可，没有包含签名文件、密钥、个人账号信息。图片是手机界面截图，发布前如需更干净的画面可以裁掉状态栏。

发布后各平台的公开链接不在这个目录里维护，去平台的创作者后台查。
