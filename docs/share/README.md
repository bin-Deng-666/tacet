# 分享材料

发布到小红书、抖音、B 站的图文素材与文案。

这套材料不是同一份内容复制三遍。三个平台的标题长度算法、封面比例、标签体系、配乐要求都不一样，所以按平台分别准备。

## 目录

```
小红书/    6 张 1080×1440（3:4） + 文案.md
抖音/      6 张 1080×1440（3:4） + 文案.md
B站/       1 张 1920×1080（16:9）封面 + 5 张 1080×1440 配图 + 文案.md
```

每个平台的 `文案.md` 包含：标题候选（已按该平台长度规则校验）、正文、标签、配图顺序、发布要点、发布后不可改的项。

## 图片用途

六段顺序是固定的，从封面到上手：

| 序号 | 内容 | 作用 |
| --- | --- | --- |
| 01 | 封面 | 主图，讲清这是什么 |
| 02 | 界面 | 真实手机截图，作为证据 |
| 03 | 能力 | 三个能力分别是什么 |
| 04 | 边界 | 先说做不到的 |
| 05 | 常见问题 | FAQ |
| 06 | 上手 | 安装步骤 + 仓库地址 |

首图必须用 `01-封面.png`，不要换成截屏。

## 平台差异

| | 小红书 | 抖音 | B 站 |
| --- | --- | --- | --- |
| 形态 | 图文笔记 | 图文作品 | 专栏 |
| 标题上限 | 20（ASCII 每 2 字符计 1） | 20 | 80，建议 30 内 |
| 图片比例 | 3:4 | 3:4 | 16:9 封面 + 3:4 配图 |
| 配乐 | 不需要 | **必须选，发布后不可改** | 不需要 |
| 发布后图片 | 可换 | **不可改** | 可改 |
| 修改额度 | 无上限 | 每作品 5 次 | 每篇 3 次 |

抖音的配乐只能在发布页「扩展信息 → 选择音乐」里选，编辑页没有音乐控件。要求无歌词、无人声、时长 ≥ 60 秒。

B 站专栏正文支持小标题和代码块，但**不支持 Markdown 标记**。直接粘贴 `文案.md` 里的内容前，需要先去掉 `**`、`##`、代码块围栏，否则会显示成一片符号。

## 重新生成

图片是用脚本从真实手机截图排版生成的，截图来自应用实际运行状态（首页、设置、应用保护选项、运行记录）。

如果界面改了，图片需要重新拍截图再重排。文案里的数字（源码行数、APK 体积、测试项数）跟随版本变化，改版后需要同步更新：

- 源码行数：`find src -name '*.java' | xargs wc -l`
- APK 体积：构建后看 `tacet.apk` 大小
- 测试项数：`test/CoreTests.java` 与 `test/DeviceTests.java` 的检查条数

## 注意

材料里公开了仓库地址和 MIT 许可，没有包含签名文件、密钥、个人账号信息。图片是手机界面截图，右侧状态栏的部分系统图标可见，发布前如需更干净的画面可以裁掉。

发布后各平台的公开链接不在这个目录里维护，去平台的创作者后台查。
